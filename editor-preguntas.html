Cómo se usa

1. Crea o abre

Pulsa Nueva lista para empezar desde cero o Abrir archivo para cargar uno ya hecho.

2. Escribe las preguntas

Cada tarjeta tiene una pregunta y su respuesta. Puedes añadir, duplicar o borrar las que quieras.

3. Guarda tu archivo

Pulsa Guardar archivo. El archivo se guardará en el formato que necesita el juego.

Este editor acepta archivos normales de preguntas y también archivos con preguntas o questions dentro.
